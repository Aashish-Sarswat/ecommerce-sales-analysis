# E-Commerce Sales Analysis

## Project Overview

This is a beginner-level exploratory data analysis project based on e-commerce sales data.

The goal of this project is to understand sales performance across products, categories, cities, payment methods, and months.

## Tools Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Data Cleaning

The following data-cleaning steps were performed:

- Checked missing values
- Removed duplicate rows
- Converted Order_Date to datetime
- Handled missing Price, City, and Payment_Method values
- Created a Sales column using Quantity × Price

## Analysis Performed

- Total sales analysis
- Average order value
- Product-wise sales
- Category-wise sales
- City-wise sales
- Payment-method analysis
- Quantity sold by product
- Monthly sales analysis
- Sales distribution
- Outlier analysis

## Key Insights

- Electronics generated the highest revenue among categories.
- Laptop generated the highest product-level revenue.
- beckpack had the highest quantity sold.
- Indore generated the highest sales among cities.
- January had the highest monthly sales in this dataset.
- Sales distribution contains some high-value orders.

## Conclusion

This project demonstrates a basic end-to-end exploratory data analysis workflow using Python, Pandas, NumPy, Matplotlib, and Seaborn.
